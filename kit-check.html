Formatting Rules — Common Mistakes

MistakeWhat happensFix
Missing comma after an entryBlank page — syntax errorEvery entry needs a comma except the very last one before the closing bracket.
Extra comma after the last entryBlank page — syntax errorRemove the trailing comma from the last entry.
Lowercase valueQC misses the matchAll categories, formats, and phrases must be UPPERCASE.
Wrong quotes (curly instead of straight)Syntax errorUse straight quotes only. Never edit in Word — it auto-replaces with curly quotes.
Changes not showingBrowser cached old versionPress Ctrl+Shift+R to hard-refresh.

Important Decisions — Do Not Change Without Reading the Decisions Log

Rule / BehaviourWhy it exists — do not revert
Duplicate matching is exact including extensionFiles like 22_27a_1.chk and 22_27a_1.lst are different files. Fuzzy matching caused false positives on extension and numeric variants (-1.0 vs 1.0).
Acceptable/Poor/Extremely Poor + blank Exception Code does NOT flag (XOM)Files reading back complete from degraded media get no exception code per governance doc. Reverting generates hundreds of false failures.
LAS-DLIS-Must-Be-Blank applies to WELL LOG/WIRELINE (no exemption)For WELL LOG/WIRELINE with DLIS or LAS format, Title and Description must be BLANK, same as every other category. LIS format is not included in this rule. Corrected 2026-07.
NAVIGATION exempt from all duplicate checksNav data legitimately reuses filenames across many media items — not a real duplicate.
Report dedup key is KDM Item ID + Field + RuleMulti-media items appear on many export rows. Row-number key caused same issue to appear N times per item.
